# DevTrail

面向开发者的项目学习与资料工作台。

> 文档初版，随开发更新。更新日期：2026-11-03。
> 计划功能与实际实现分别记录，以代码为准。

## 项目目标

帮助开发者围绕实际项目问题管理资料、记录实践，整理可追溯的学习报告。

核心流程：**记录问题 → 查找资料 → 收藏阅读 → 记录实践 → 整理学习报告**。

例如：遇到 Vue 列表滚动卡顿，记录问题、检索并收藏资料，记录优化尝试和结果，再选择相关内容生成 Markdown 学习报告。

本项目也用于学习完整项目开发，并用于求职展示和比赛。目标是在 2026 年 12 月 31 日前完成可部署、可使用版本，每周投入约 20～30 小时（包含学习时间），范围随实际进度调整。

### 设计原则

- 收藏是总资料库，同一份资料可以关联多个项目或问题。
- 实践进度与实践结果分别记录，例如“准备尝试／已尝试”和“有效／不适用”。
- 报告仅纳入用户选中的内容，区分外部资料、个人理解和实际完成情况。
- 保存的报告保留生成时的内容，并能追溯来源。
- 收藏或阅读不等于实践完成；AI 不得编造个人成果。
- 推荐链接来自真实检索结果，保留来源和相关性说明。
- 第一版关联仓库只保存链接，不自动分析代码。

暂不纳入年底版本：任意网页爬虫、代码自动分析、复杂 Agent、向量数据库、多人协作、自由拖拽首页。全网博客搜索为扩展项。

## 技术栈

当前已使用：Vue 3、TypeScript、Vite、原生 CSS、npm。Vue 组件采用 Composition API 和 `<script setup>`，具体依赖见 `package.json`。

以下为后续计划，不代表已经安装：

| 方向 | 计划技术 |
| --- | --- |
| 前端组织 | Vue Router、Pinia、Element Plus |
| 请求与内容 | Fetch、TanStack Vue Query、DOMPurify |
| 后端 | Node.js、TypeScript、Express、rss-parser、Zod |
| 数据库 | SQLite、better-sqlite3，先编写基础 SQL |
| 登录 | Session＋Cookie，持久化会话存储 |
| 工具与验证 | Git、ESLint、Prettier、类型检查、Vitest、Playwright |
| 外部能力 | RSS／Atom、GitHub API、一个模型 API |

Pinia 计划管理界面共享状态；Vue Query 管理服务器数据，避免重复保存同一份文章列表。

模型供应商及预算尚未确定。公开订阅源和 GitHub 存在访问、额度限制，AI 不保证免费。依赖在对应开发阶段按需引入。

## 本地运行

在 PowerShell 进入前端目录：

```powershell
cd "C:\3G实验室\前端项目\DevTrail\frontend"
```

首次获取项目且尚未安装依赖时执行 `npm install`。当前本地已安装依赖，可启动：

```powershell
npm run dev
```

打开终端显示的地址，之前使用 `http://localhost:5173/`，实际端口以终端为准。停止服务按 `Ctrl+C`。

请在包含 `package.json` 的 frontend 目录执行 npm 命令；在上一级 DevTrail 目录运行会出现找不到 package.json 的 ENOENT 错误。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 先执行 Vue／TypeScript 类型检查，再构建生产资源 |
| `npm run preview` | 本地预览构建产物，需要先运行 build |

## 前端目录

```text
frontend/
├─ docs/
│  └─ roadmap.md           阶段路线、验收标准与开发准备
├─ src/
│  ├─ main.ts              创建 Vue 应用、引入全局样式并挂载根组件
│  ├─ App.vue              根组件，当前包含首页、项目数据和状态切换
│  ├─ style.css            全局盒模型、背景、字体和正文颜色
│  ├─ components/          可复用组件；HelloWorld.vue 是未使用的模板示例
│  └─ assets/              由源码导入的图片等资源
├─ public/                 按原路径提供的静态资源
├─ index.html              HTML 入口，提供 #app 挂载位置
├─ package.json            依赖声明及运行脚本
├─ package-lock.json       依赖版本锁定文件
├─ vite.config.ts          Vite 配置
├─ tsconfig*.json          TypeScript 配置
└─ README.md               项目说明、运行方式和阶段进度
```

页面入口关系：`index.html → src/main.ts → src/App.vue`。

## 下一步与协作约定

下一步：由用户建立 GitHub 仓库后，准备提交第一阶段代码；提交完成后开始第二阶段“问题与实践”，先细化数据模型和验收标准，再逐步开发。

协作方式：

1. 每次只推进一个可理解、可验证的小步骤，修改前先读取实际代码。
2. 说明修改位置、原因和验证方法，核心业务由学习者参与实现。
3. 结合当前代码解释 Vue、TypeScript、数据流及工程设计原因。
4. 保留已有调整，包括按钮默认渐变 `linear-gradient(135deg, #ddf4f5, #dbf1e6)`。
5. 完成一个阶段后，同步更新实现状态、验证情况与下一步。
6. 按当前约定，第一阶段验收完成后再进行 Git 提交。

数据库设计、接口约定、测试说明、部署步骤和关键技术决策，在对应功能开发时逐步补充。
