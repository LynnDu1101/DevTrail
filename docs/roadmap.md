## 第一条可用流程

第一阶段：打开首页 → 创建学习项目 → 修改名称和目标 → 切换完成状态 → 刷新后继续查看 → 删除不需要的项目。

后续逐步扩展为：创建项目 → 记录问题 → 查找并收藏资料 → 记录实践及结果 → 选择内容并导出学习报告。

### 结束标准

以下为第一阶段验收依据；已执行结果见“第一阶段验证记录”，未完成检查统一列在文末“保留项”，不代表所有视觉与键盘场景均已实测。

1. 新增有效项目后出现对应卡片；空白输入被阻止，并显示提示。
2. 多个项目 id 唯一；操作任意一个项目不会改变其他项目。
3. 编辑后名称和目标正确更新；取消编辑不改变原数据。
4. 删除确认生效，取消不删除；删空后出现提示且仍可新增。
5. 新增、编辑、删除和状态切换的结果刷新后保留；主动清空列表后刷新，不会重新出现示例项目。
6. 无保存数据、损坏数据、存储读写失败时页面不崩溃；保存失败有提示。
7. 窄屏下表单和卡片无明显横向溢出；键盘能操作输入框和按钮。
8. npm run build 通过；浏览器操作无未处理错误；记录实际验收结果。
9. 学习者能解释响应式数组、v-for、key、函数参数、表单绑定和本地保存的基本作用。

## 第二阶段：问题与实践

状态：核心功能与本次约定验收完成，第二阶段已提交并推送 GitHub（2026-11-10，`73a32db`）；下列保留项不记为已验证。

### 数据模型与功能范围

- Issue：id、projectId、title、description、status（待解决／已解决）。
- Practice：id、issueId、title、content、progress（准备尝试／尝试中／已尝试）、result（未评估／有效／无效／不适用）。标题不能为空白，content 可为空字符串但字段不可缺失；id 为正安全整数且不可重复。
- 问题与实践均支持新增、独立编辑草稿、取消、删除与 localStorage 读写；实践新增默认准备尝试／未评估，进度和结果可独立编辑。
- 删除问题或项目清理关联实践及所属草稿、编辑状态；读取时过滤历史孤立实践，上游读取不可靠时跳过过滤。过滤先作用于内存，下次实践成功保存时写回。

### 实践管理及界面验收

- 用户浏览器确认：实践新增与空白提示、过程可空、取消清理、编辑与跨记录隔离、删除、进度和结果修改、刷新保留；删除问题及项目的关联实践清理通过。
- 用户确认：实践合法空数组、损坏 JSON 与恢复保存、非数组及非法元素、重复 id、必要字段缺失验收通过。
- 助手独立无界面 Edge、隔离浏览器配置和测试数据：非法 progress、非法 result 均提示格式错误并拒绝列表；合法对照正常显示。
- 同上：实践写入抛错时内存记录保留且提示失败；恢复写入、编辑保存后提示消失，刷新保留。实践 getItem 抛错时提示读取失败，上游页面可用，存储未被覆盖；恢复后原实践完整显示。
- 同上：正常实践保留、孤立实践过滤并提示，初次读取不改写存储；编辑正常实践后存储清理，刷新保留。问题 JSON 损坏时实践不误清理、不覆盖存储，恢复问题数据后原实践完整显示。
- 表单取消跳动在独立 Edge 复现：收起导致页面高度缩短，浏览器回调滚动位置。增加高度过渡及视口所需最小高度后，用户确认效果；已推广到条件新增／编辑表单，并修复展开过早释放高度及问题编辑表单间距。
- 上述测试使用临时脚本，执行后已删除；不是仓库内可重复运行的测试套件。未添加测试依赖。
