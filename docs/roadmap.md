# DevTrail 开发路线与验收

更新日期：2026-11-03。第一阶段功能开发与已执行验收完成；第二阶段及以后为计划。极窄屏按钮换行保留视觉验证项。

## 第一条可用流程

第一阶段：打开首页 → 创建学习项目 → 修改名称和目标 → 切换完成状态 → 刷新后继续查看 → 删除不需要的项目。

后续逐步扩展为：创建项目 → 记录问题 → 查找并收藏资料 → 记录实践及结果 → 选择内容并导出学习报告。

## 第一阶段：项目管理基础

目标：完成能在当前浏览器中持续使用的项目管理页面。第一阶段使用 localStorage 保存数据；后端、账号和跨设备同步安排在后续阶段。

### 结束标准

以下全部通过，第一阶段才算结束；列表渲染完成只是其中一步。

1. 新增有效项目后出现对应卡片；空白输入被阻止，并显示提示。
2. 多个项目 id 唯一；操作任意一个项目不会改变其他项目。
3. 编辑后名称和目标正确更新；取消编辑不改变原数据。
4. 删除确认生效，取消不删除；删空后出现提示且仍可新增。
5. 新增、编辑、删除和状态切换的结果刷新后保留；主动清空列表后刷新，不会重新出现示例项目。
6. 无保存数据、损坏数据、存储读写失败时页面不崩溃；保存失败有提示。
7. 窄屏下表单和卡片无明显横向溢出；键盘能操作输入框和按钮。
8. npm run build 通过；浏览器操作无未处理错误；记录实际验收结果。
9. 学习者能解释响应式数组、v-for、key、函数参数、表单绑定和本地保存的基本作用。

时间安排：以验收结果为准，暂不承诺具体日期。建议预留约 1～2 周（每周 20～30 小时，包含学习与调试），完成新增和编辑后再校准估算。
